Findings:
- [high] EXP-015's null does not establish split-specific M0 prediction (lab/experiments/EXP-015-mask-spectrum/mask_spectrum.py:57-81)
  Phase 2 reads K from baseline seed s and reconstructs M0 from split seed s, while that baseline also uses init seed s. The only test compares the resulting rank against uniformly random frequency ranks; it never permutes observed masks across runs, independently crosses init and split, or implements the README-promised E0/G0 comparisons. A same-seed coupling, shared frequency preference, or another split statistic correlated with M0 can therefore be labelled “confirmed.” This matters because M0 was formulated after G0 selection and the split-dominant preview on seeds 0–9, making phase 1 exploratory rather than independent evidence.
  Recommendation: On untouched independently crossed init/split runs, compare matched M0 against foreign-mask permutations and prespecified alternative mask statistics. Implement the registered E0/G0 paired comparisons and treat phase 1 strictly as exploratory.
- [high] The engineered test set controls both censoring and the frequency-measurement endpoint (lab/experiments/EXP-001-freq-ban/freq_ban.py:326-337)
  For a complement mask T=1−M, every non-DC Fourier coefficient is the negative of M's coefficient, so the engineered test set has exactly the same M0 power peaks as the training set. The runner stops relative to the first threshold crossing on that treatment-defined test set and then computes final_top_m_freqs at that variable step; EXP-016 also excludes runs that never cross. This can select target-aligned runs and compare K at systematically different stages. The random-split baseline does not control this test-distribution and stopping-rule change.
  Recommendation: Train all arms to the same preregistered step and measure K at common checkpoints independent of test crossing. Evaluate a fixed full-grid metric, retain failures as outcomes, and add same-init engineered controls targeting different frequency sets with matched construction strength.
- [high] EXP-014 independently sign-flips statistically dependent rows (lab/experiments/EXP-014-split-vs-init/analyze.py:27-56)
  The cyclic design reuses each baseline: B_(i+1) contributes positively to D_i and negatively to D_(i+1). Nevertheless, two_sided_p independently flips every D_i, enumerating assignments that the design could never generate and assuming coordinate-wise sign symmetry despite the shared controls. With only ten rows, the resulting p-value can be materially anti-conservative and trigger “Split dominiert” without valid evidence.
  Recommendation: Use a balanced crossed design with multiple independently randomized partners and estimate init/split effects directly, or construct a design-level permutation that reassigns split labels as a whole while preserving baseline reuse and dependence.
- [medium] Malformed split files silently corrupt the train/test partition (lab/experiments/EXP-001-freq-ban/freq_ban.py:218-222)
  The loader casts arbitrary input to int64 and indexes it without validating dimensionality, original dtype, expected count, uniqueness, or bounds. Duplicate indices silently reweight training examples; negative indices wrap during torch indexing but remain absent from setdiff removal, placing the same pair in both train and test; floats are silently truncated. EXP-016 later validates only the filename suffix, so such a run can be accepted as valid evidence.
  Recommendation: Before indexing, require a one-dimensional integer array of exactly round(train_frac*p*p) unique values in [0,p*p). Store a content hash and have EXP-016 compare the run's split_hash against the preregistered .npy contents rather than its filename.
