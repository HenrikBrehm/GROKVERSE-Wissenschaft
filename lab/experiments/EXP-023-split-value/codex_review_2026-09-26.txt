Findings:
- [high] The intervention does not isolate parameter sharing (lab/experiments/EXP-023-split-value/split_value.py:37-42)
  W_V1 is independently sampled, so the treatment changes the model's initial function as well as untying future updates and adding 16,384 weight-decayed parameters. At the first backward pass, W_E's gradient depends on the numerical value transform, not whether equal matrices are registered as one or two parameters: copying W_V into W_V1 would reproduce the baseline gradient. Therefore a final spectrum shift cannot be attributed specifically to removal of shared-path interference. The promised first-gradient manipulation check is also absent from analyze.py.
  Recommendation: Add a copy-initialized, subsequently untied arm, a parameter/init-matched control, and compute the preregistered cross-term statistic using the exact converted model before interpreting the final spectrum causally.
- [high] The primary test can confirm using only already-inspected control outcomes (lab/experiments/EXP-023-split-value/analyze.py:20-22)
  The analysis hard-codes seeds 10–19 but accepts eight valid pairs. README.md explicitly reports the favorable M0c baseline result for seeds 10–17 before this hypothesis was defined, so those eight inspected controls alone can yield a confirmatory verdict. Because Delta_d subtracts those realized baseline outcomes while W_V1 supplies a fresh random draw, conditioning on the known M0c advantage creates regression-to-the-mean bias toward positive Delta_d; the sign-flip reference distribution does not account for that selection.
  Recommendation: Use entirely fresh, unseen seed pairs with both baseline and split-value outcomes preregistered before inspection; do not permit the known 10–17 controls to constitute the confirmatory sample.
- [high] The endpoint conditions on treatment-affected generalization (lab/experiments/EXP-023-split-value/analyze.py:39-50)
  Any arm that fails to cross is discarded, yet eight survivors are enough for a verdict. This preferentially removes seeds where the intervention prevents or severely delays grokking. Among survivors, final_top_m_freqs is measured at each arm's own gen+25, so baseline and treatment are compared after different numbers of optimizer and weight-decay steps—precisely when changed grokking time is an expected treatment effect. Spectrum differences therefore mix frequency preference, survivorship, and training duration.
  Recommendation: Make a fixed common training step the intention-to-treat primary endpoint for every seed, retain non-crossers, and report gen+25 only as a phase-aligned sensitivity analysis.
- [medium] Protocol-incompatible completed runs are silently accepted (lab/experiments/EXP-023-split-value/analyze.py:39-45)
  The run ID does not encode --steps or --stop-after-gen, completed directories are skipped, and the analyzer verifies neither max_steps=15000 nor stop_after_generalization=25, seed, condition, m, threads, or configuration compatibility. An earlier or accidental run with the same directory name but a different stopping budget can therefore be reused and treated as the preregistered gen+25 endpoint. The step-zero check is only a lossy W_E power spectrum comparison, not the claimed equality of all shared initial parameters.
  Recommendation: Fail closed on every preregistered metadata field, include stopping settings in the run identity, and record/compare a checksum of all shared initial parameters.
- [medium] Saved split-value models cannot be reconstructed correctly (lab/experiments/EXP-023-split-value/split_value.py:41-42)
  The variant exists only as an instance-level forward monkey patch. state_dict records W_V1 but not the override, while the recorded config still builds an ordinary OneLayerTransformer.
